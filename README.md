# The 1% Outage

An interactive explainer for a reliability phenomenon from the Copysets paper (Cidon et al., USENIX ATC 2013):
two storage clusters with identical replication, identical storage overhead, and identical *expected* data loss
can differ by hundreds of times in how often they lose any data at all.

- **Live demo:** https://seshseshadri.github.io/one-percent-outage/prototype/
- **Code:** `prototype/index.html`, a single static page with no build step and no backend.
- **Research:** `research/` holds the investigation of an earlier idea (model routing on public eval data) that
  the data did not support, kept for the record.
